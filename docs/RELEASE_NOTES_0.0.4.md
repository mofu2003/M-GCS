# M-GCS 0.0.4 发布说明

发布日期：2026-09-23

## 版本定位

0.0.4 是一次面向“功能闭环和前后端边界”的功能版本。它没有推倒现有 C++ Core、C FFI 和 Flutter 三层结构，而是在应用层补齐任务、安全、多机、日志/文件和可替换前端壳层的接缝。

## 本版本完成内容

### 应用层与前后端解耦

- 通过 `SessionCapabilities` 统一发现连接、参数、任务、围栏、Rally、日志、文件、多机和飞行控制能力。
- 继续保持 Flutter 页面不直接访问 MAVLink 或 `dart:ffi`；MgCore 适配集中在 `application/mgcore/`。
- 增加 `FleetController`、`SafetyController`、任务编辑控制器和飞行控制模型，页面只消费状态和动作回调。
- 增加可替换的前台 shell/skin contract，MacGlass 只是当前默认外壳。

### 任务规划与安全

- 支持本地航点创建、从地图坐标添加航点、编辑高度/速度、删除和调整顺序。
- 增加任务校验、JSON/CSV 导出、任务上传/下载/清空/设置当前项及进度展示。
- 增加围栏点配置、校验、启用/禁用、JSON 导入、JSON/KML 导出、下载和清空。
- 增加 Rally 任务下载、查看和清空入口。

### 飞行日志与飞控文件

- 新增“飞行日志”后台页面。
- 可浏览飞控内存卡的目录和文件，而不要求拔卡或使用读卡器。
- 支持选择文件、保存到本机、显示下载进度、取消下载。
- 支持从本机选择文件并上传到飞控目录，显示上传进度。
- 该能力基于 MAVLink FTP，不能把“文件传输成功”误认为“日志已经解析分析完成”；曲线、回放和诊断分析仍在后续计划中。

### 多机与飞行控制

- 支持发现已连接飞控、切换活动飞控和多选目标。
- 支持批量解锁、上锁、返航、降落和模式切换，并记录逐机结果。
- 批量操作结束后恢复原活动飞控，避免破坏用户当前上下文。
- 危险批量操作在 UI 层增加二次确认。

### UI、本地化和工程工具链

- 前台、后台和连接/地图相关组件继续统一 MacGlass/macOS 视觉语言。
- 增加中英文 ARB 资源、生成绑定和 key/占位符/术语一致性测试。
- 固定 Flutter 工具链基线为 `.flutter-version` 中的 Flutter 3.44.9。
- macOS 工程最低部署版本提升到 macOS 12.0，与当前 Flutter/Xcode 构建基线保持一致。

## 已知限制与下一步

1. 当前多机批量命令仍通过“切换活动飞控 → 执行 → 恢复活动飞控”工作；长期应在 native/FFI 中增加显式 `vehicle_id` 目标，消除临时路由耦合。
2. Mission Planner/QGroundControl 级别的完整命令覆盖、测绘相机模型、地形跟随、日志曲线/回放、MAVLink Inspector 和离线地图包尚未完成。
3. Camera、gimbal、video 的底层接口已有部分基础，但 Flutter 端还没有完整工作流。
4. 固件刷写、移动端工程、真实硬件写操作和多平台发布包仍需要单独的安全验收。

## 升级提示

- 应用版本号为 `0.0.4+4`。
- 首次构建前仍需按 [开发指南](DEVELOPMENT.md) 生成本地 MAVLink C 头文件；生成物不提交到仓库。
- 真实飞控测试前必须确认飞控未解锁，并明确本次测试会发送的命令。

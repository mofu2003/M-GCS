# M-GCS 路线图

当前版本：`1.0.0`。本文件描述当前能力和可能方向，不承诺固定版本、日期或平台交付。

## 当前范围

M-GCS 当前面向 ArduPilot 地面站，主要工作流包括：

- 串口、UDP、TCP 连接、重连、心跳和多机隔离；
- 遥测、姿态、GPS、电池、飞行模式和连接状态显示；
- 带 ACK/超时/拒绝结果的飞行命令；
- 任务文档编辑、校验、导入导出、上传、下载、围栏和 Rally；
- 参数读取、写入回读、搜索和配置页面；
- 陀螺、加速度计、罗盘、气压计和遥控器校准；
- 机载日志、`.tlog` 录制/回放和 MAVLink FTP 文件操作；
- 相机、云台及视频流元数据；可选本地视频解码、预览、录制和截图。

具体导出数量、前端绑定数量和平台可用性不要从本文件推断，以 `bridge/ffi/ffi_api*.h` 和 `python3 tools/check_ffi_contract.py` 的输出为准。

## 当前不承诺

- PX4 或其他非 ArduPilot 固件支持；
- 固件刷写、自动测绘、地形高程和编队控制；
- 所有平台都具备相同的本地视频解码后端；
- 未经当前代码和硬件验证的硬件型号、协议和性能。

这些方向将来是否实现，应在出现真实需求后按实际调用链设计，不预先建立工厂或规则体系。

## 后续方向

可以考虑日志解析与图表、遥测历史曲线、断点续传、离线地图或移动端适配。它们只是候选方向，优先级以真实用户需求、可验证收益和当前维护成本为准。

## 完成线

当前阶段的完成标准见根目录 `AGENTS.md`：能构建，相关测试通过；真实 bug 有复现路径、后果和回归测试；错误语义、依赖方向和车辆/会话绑定没有被破坏。

# M-GCS 开发路线图

当前版本：1.0.0（2026-10-13）

## 核心目标

M-GCS 是 ArduPilot 固件的地面站，对标 QGroundControl 与 Mission Planner。核心理念：可替换 Flutter 前端、稳定的 C FFI 接口、核心状态独立可测、对飞行风险采用明确的拒绝/过期/未知语义。

---

## 架构规则

遵循 `docs/constraints/` 下的约束体系：

- **A1**: Core 不依赖 Bridge/UI
- **A2**: 模块无环（Transport / MAVLink / Firmware）
- **A3**: 持锁路径禁止阻塞 I/O
- **S1-S8**: 飞行安全规则（见 `docs/constraints/safety.md`）
- **U1-U8**: UI 设计系统规则（见 `docs/constraints/ui.md`）

详细规则见 `docs/constraints/architecture.md`。

## 版本策略

- **1.0.0+**: 基于 ArduPilot，优先稳定
- **破坏性变更**进主版本号（Major）
- **新功能**进次版本号（Minor）
- **修复**进补丁号（Patch）

从 1.0.0 起采用 SemVer，不再向后兼容 0.x 版本。

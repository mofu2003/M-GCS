# 无人机课程介绍

本课程从零开始装出一架无人机，逐步做到多架无人机编队协同飞行。共五个部分，难度递进。

---

## 课程总览

```mermaid
graph LR
    A[装出一架能飞的飞机] --> B[会用地面站控制它]
    B --> C[能写程序让它自主飞]
    C --> D[能同时管多架]
    D --> E[多架编队协同]
```

一句话概括：先装好一架，再学会控制它，最后让它自己飞、并且和别人一起飞。

---

## 五个部分

### 第一部分：无人机组装与调试

从零把一架无人机装起来。机架、电机、电调、飞控怎么连，装好之后怎么让它稳定飞起来，飞得不好怎么改参数。

- 学员得到什么：能独立装出一架能飞的飞机
- 难度：动手为主
- 前置要求：无

### 第二部分：地面站使用

地面站是电脑上控制无人机的软件。用它看飞行状态、规划航线、改参数、看日志。

- 学员得到什么：能用电脑监控和控制飞机
- 难度：动手 + 软件
- 前置要求：会基本电脑操作

### 第三部分：机载计算与程序控制（Linux / RK3576）

用一块 RK3576 开发板当机载电脑，装在飞机上，用 Linux 系统给它写程序，让无人机不只是听遥控器，还能自己执行任务。

- 学员得到什么：能写程序让飞机自主执行任务
- 难度：需要写代码
- 前置要求：一点 Linux / Python

### 第四部分：多机通信与协同

一架飞好了，做几架一起飞——怎么让它们互相通信、不打架、听同一个指令。

- 学员得到什么：能同时管多架飞机
- 难度：需要写代码 + 调网络
- 前置要求：第三部分

### 第五部分：编队飞行与蜂群

多架飞机按队形飞，像一群鸟一样协同。这是前面所有内容的综合应用。

- 学员得到什么：能让多架飞机按队形协同飞行
- 难度：综合
- 前置要求：前面全部

## 难度递进

| 阶段 | 难度 | 需要的前置 |
|---|---|---|
| 组装调试 | 动手为主 | 无 |
| 地面站 | 动手 + 软件 | 会基本电脑操作 |
| Linux 控制 | 要写代码 | 一点 Linux / Python |
| 多机连调 | 要写代码 + 调网络 | 上一阶段 |
| 编队蜂群 | 综合 | 前面全部 |

## 开场白（可直接照念）

> 这门课分五个部分，从最简单的动手装飞机开始，最后做到多架无人机编队飞行。
>
> **第一部分，组装和调试。** 我们从零把一架无人机装起来——机架、电机、电调、飞控怎么连，装好之后怎么让它稳定飞起来，飞得不好怎么改参数。
>
> **第二部分，地面站操作。** 地面站是电脑上控制无人机的软件。用它看飞行状态、规划航线、改参数、看日志。
>
> **第三部分，用 Linux 控制无人机。** 我们会用一块 RK3576 开发板当机载电脑，装在飞机上，用 Linux 系统给它写程序，让无人机不只是听遥控器，还能自己执行任务。
>
> **第四部分，多机连调。** 一架飞好了，我们做几架一起飞——怎么让它们互相通信、不打架、听同一个指令。
>
> **第五部分，编队与蜂群。** 多架飞机按队形飞，像一群鸟一样协同。这是前面所有内容的综合应用。
>
> 前两部分是动手为主，第三部分开始要写代码，用得到 Linux 和 Python。没接触过的同学不用慌，我们会带着做。

# 顶层状态详情页滑块切换设计

> 归档说明：这是历史临时规格草稿，不属于当前开发基线。文中涉及的前端路径和组件代表当时的实现上下文，不表示当前源码包仍包含这些历史文件。

## 目标

在不改动现有顶层展开/收起动画边界的前提下，调整四个顶层状态详情页的内部结构：

- 四个顶层详情页面板统一增高一个 GPS 标签高度
- `GPS` 页面增加二级滑块切换：`GPS 配置` / `电子围栏`
- `电池` 页面增加二级滑块切换：`电池配置` / `失控保护`
- `告警` 页面增加二级滑块切换：`警报信息` / `解锁检查`
- `飞行模式` 页面本轮只加高，不改内部结构

本次只处理前端展示结构和切换方式，不新增业务接口，不扩展后台能力。

## 现状

- 顶层状态详情页当前由 `app/lib/features/status_bar/status_bar_bootstrap.dart` 负责展开形变和内容承载。
- 当前面板内容只有标题，没有二级切换和分页面内容。
- 当时的连接面板 `app/lib/features/connection/connection_panel.dart` 已经有成熟的滑块分段切换样式 `_SegmentedTabs`，视觉和交互可直接复用。

## 方案

### 1. 复用现有滑块样式

把连接面板内的 `_SegmentedTabs` 抽成可复用组件，放到状态页和连接页都能共用的位置。

这样做的原因：

- 保持视觉一致
- 避免重复写一套滑块逻辑
- 只做一次测试

### 2. 状态详情页内容结构

继续由 `StatusBarBootstrap` 承担状态详情面板的展开动画，不新建额外动画容器。

面板内容调整为：

- 顶部标题
- 如当前页需要二级切换，则显示滑块分段切换
- 下方显示对应二级页面内容

其中：

- `GPS`、`电池`、`告警` 显示二级滑块
- `飞行模式` 不显示二级滑块，保留单页内容

### 3. 高度策略

当前状态详情面板展开后的目标高度是 `56 * 3`。

本次统一调整为：

- 原高度 + 一个 GPS 标签高度
- 即再增加 `56`

这样四个顶层页高度一致，动画目标高度也一致，避免不同页面高度不一带来的切换抖动。

### 4. 内容策略

本轮不发明新的业务内容模型，只做最小可用结构：

- 每个二级页先使用现有状态详情信息或简洁占位内容承接
- 占位内容命名直接对应页面名，避免业务语义漂移
- 后续如果要补真实配置项，再在对应子页内逐步填充

### 5. 动画和交互边界

必须保持以下边界不变：

- 顶层状态页展开/收起的主动画仍由现有 `StatusBarBootstrap` 控制
- 二级页切换只在已展开的详情面板内部发生
- 二级页切换不能干扰顶层状态页和连接页的互斥逻辑
- `飞行模式` 因本轮不做二级切换，不引入额外状态

## 影响文件

- 修改：`app/lib/features/status_bar/status_bar_bootstrap.dart`
- 修改：`app/lib/features/connection/connection_panel.dart`
- 新增或调整：一个可复用的分段切换组件文件
- 修改：相关 widget 测试

## 测试策略

补充 widget 测试，至少覆盖：

- `GPS` 页面显示 `GPS 配置` / `电子围栏` 两个滑块项，并可切换
- `电池` 页面显示 `电池配置` / `失控保护` 两个滑块项，并可切换
- `告警` 页面显示 `警报信息` / `解锁检查` 两个滑块项，并可切换
- `飞行模式` 页面不显示滑块切换
- 面板展开后高度按新值渲染
- 现有顶层状态页展开/关闭回归测试继续通过

## 范围外

本轮不包含：

- `飞行模式` 二级页面设计
- 真实参数表单、保存逻辑、后台交互
- 新的状态页动画体系
- 工具菜单、连接面板、地图或遥测布局改版

# ADR 0005：旧任务规划领域决策（已废止）

## 状态

**已废止**（2026-09-30）。本文件仅保留决策历史，不再作为当前设计依据。

## 废止说明

项目不再采用 Mission CAD 作为产品概念，也不再使用“CAD 文档”“CAD 几何”等术语
描述任务规划功能。当前概念是**任务文档**与**任务规划**：用户编辑由稳定实体、命令、
坐标和参数组成的任务；后端校验并编译为面向飞控的 `MissionPlan`。

当前有效的边界和行为以以下文档为准：

- [`docs/ARCHITECTURE.md`](../ARCHITECTURE.md) 的“任务规划领域边界”。
- [`docs/MISSION_PLANNING.md`](../MISSION_PLANNING.md) 的任务文档契约。
- [`bridge/ffi/API_CATALOG.md`](../../bridge/ffi/API_CATALOG.md) 的 FFI 契约。

## 历史记录

本 ADR 曾提出把参数化航线设计文档、几何约束与编译放在后端领域层，避免不同前端
各自实现编译逻辑。该技术边界中仍然适用的部分，已转述到当前架构文档；“CAD”这一
产品概念、术语及其专属设计设定不再有效。

实现代码和既有 ABI 尚未随术语决策重命名：`core/mission/cad/` 是现有内部目录，
`mg_mission_doc_*` 是已发布接口名。它们是实现/兼容细节，不构成继续采用 Mission CAD
概念的依据。未来是否重命名目录或接口需单独评估兼容性，不属于本 ADR 的废止范围。

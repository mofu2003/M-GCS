# ADR 0006：波形显示管线——采集保真、显示可读

## 状态

已采纳。

## 背景

传感器波形页要同时满足两个互相拉扯的要求：校准和排障时毛刺本身是有效信息，必须原样保留；
而操作员又要能读出稳定的数值、对同一段曲线做跨时间比较。把这两件事混在一条管线里，
就会出现"为了让界面好看而偷偷改数据"的做法——滤波、按平均抽稀、量程乱跳。

这类做法在工业地面站里代价很高：

1. 真值被抹掉后，事后复盘分不清"设备真的抖了一下"和"链路丢包造成的伪影"。
2. 操作员不知道自己看到的是原始值还是处理过的值，无法据此判断故障。
3. 量程频繁变化会让曲线整体缩放，跨时间比较失去意义，看起来像"数据在乱跳"。

低 CPU 占用是既定约束，因此"每帧把全部原始点传给前端再过滤一遍"这类方案本身也不成立。

## 决策

波形管线分为职责单一的五层，越靠前的层越不允许改动数据：

| 层 | 职责 | 允许的操作 |
| --- | --- | --- |
| 采集 | 全速率原始采样进环形缓冲 | 不限流以外的任何处理 |
| 记录 | 原始值写入日志，作为证据链 | 不做任何变换 |
| 降采样 | 生成给界面绘制的点集 | 只允许 min/max 包络抽稀 |
| 显示 | 决定"怎么看" | 量程、时间基、刷新节拍 |
| 交互 | 冻结、读数、导出 | 只读原始数据 |

具体约束：

1. **降采样只允许 min/max 包络**。按平均抽稀会削掉瞬态，等同于伪造数据。
   包络抽稀器的分桶边界对齐绝对时间栅格，保证同一帧数据每次落点一致。
2. **绘制曲线永远是原始采样点**，不做滤波、不加滑动平均。需要平滑视图时，
   只能作为一条额外曲线并显式标注，不能替换原始曲线。
3. **量程变化必须是低频且不裁数据的**。数据真正超出量程时立即扩量程（绝不裁掉数据），
   扩量程时预留余量，避免随后的小幅波动再次触发；收缩必须同时满足"新量程明显更小"
   和"稳定持续足够久"。
4. **刷新节拍与采样率解耦**。界面按固定节拍取数，采样率变化不得改变重绘频率。
5. **任何变换都必须在界面上可见**。数字类读数可以提供平滑值，但必须与瞬时值并列
   并写明窗口（例如"1s 均值"），不得用平滑值替换瞬时值。
6. **门限和报警判据走包络，不走均值**，否则瞬态会被漏报。

## 影响

正面影响：

- 毛刺、尖峰、瞬态在任何窗口宽度下都不会因为显示管线而丢失。
- 操作员能区分"原始值"和"平滑读数"，也能对同一段曲线做跨时间比较。
- 显示层策略集中在少数几处（抽稀器、量程跟踪器、面板），改动面可控。

成本：

- 量程策略更保守，极端值出现后曲线会在较长时间内保持较大量程，看起来"不够紧凑"。
- 需要同时维护瞬时读数和平滑读数两个概念，面板信息密度更高。
- 需要额外的包络抽稀和量程滞回测试。

## 验收条件

1. 后端包络抽稀的测试覆盖"抽稀后仍保留每个分桶的极值"。
2. 波形面板不包含任何作用于原始采样点的滤波或平均逻辑。
3. 数据超出当前量程时，量程在同一帧内扩大，不出现曲线被裁掉的情况。
4. 数字读数同时展示瞬时值和带明确窗口标注的平滑值。
5. 采样率变化或链路速率变化不改变界面重绘频率。
